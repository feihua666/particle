# 前端组件总览

Particle 的前端部分采用模块化架构，位于 `web` 目录下，主要包含以下几类前端组件：

## 前端架构概览

Particle 的前端架构分为以下几个主要部分：

1. **公共前端组件**：位于 `web/common` 目录，提供通用的前端工具和组件
2. **全局前端组件**：位于 `web/global` 目录，提供全局通用的前端功能
3. **业务组件前端模块**：位于 `web/component` 目录，对应后端业务组件的前端实现
4. **项目前端模块**：位于 `web/project` 目录，特定项目的前端实现

## 前端目录结构

```
web/
├── common/          # 公共前端模块
├── global/          # 全局前端模块  
├── component/       # 业务组件前端模块
└── project/         # 项目前端模块
```

## 公共前端组件

公共前端组件提供通用的前端工具和基础组件，包括：

- 通用工具函数
- 基础UI组件
- 网络请求封装
- 状态管理工具

## 全局前端组件

全局前端组件提供跨项目的通用功能，例如：

- 认证授权组件
- 通知消息组件
- 文件上传下载组件
- 数据表格组件

## 业务前端组件

业务前端组件与后端业务组件相对应，每个业务组件（如用户、角色、部门等）都有对应的前端实现，提供特定业务功能的用户界面。

## 项目前端组件

项目前端组件是基于上述组件构建的具体项目实现，整合了各种前端组件以构建完整的企业级应用。

## 使用建议

1. **按需引入**：根据项目需求选择需要的前端组件，避免引入不必要的依赖
2. **遵循规范**：使用前端组件时遵循其设计规范和使用约定
3. **组件复用**：优先使用已有的前端组件，避免重复造轮子
4. **扩展定制**：在需要定制功能时，通过扩展而非修改的方式进行

通过合理使用这些前端组件，您可以快速构建功能丰富、结构清晰的企业级前端应用。
