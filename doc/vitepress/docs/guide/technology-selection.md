# 技术选型

Particle 在设计和开发过程中，选择了业界成熟且广泛使用的技术栈和组件，确保系统的稳定性、性能和可维护性。

## 后端技术选型

### 核心框架

- **Spring Boot 3.x**: 作为核心框架，提供自动配置、快速开发能力
- **Spring Framework 6.x**: 提供依赖注入、面向切面编程等核心功能
- **Spring MVC**: Web 层框架，用于构建 RESTful API
- **Spring Security**: 安全框架，提供认证和授权功能
- **Maven**: Java 项目管理和构建工具

### 数据库相关

- **MyBatis-Plus**: ORM 框架，在 MyBatis 基础上增强功能，简化数据库操作
- **HikariCP**: Spring Boot 默认的数据库连接池，性能优异
- **MySQL 8.0+**: 主要关系型数据库
- **Redis**: 缓存数据库，用于高速缓存和分布式锁

### 中间件

- **RabbitMQ**: 消息队列，用于异步处理和解耦系统组件
- **Elasticsearch**: 搜索引擎，用于全文检索和数据分析
- **Quartz**: 任务调度框架，用于定时任务处理

### 工具类库

- **Lombok**: 简化 Java 代码，减少样板代码
- **MapStruct**: 对象映射工具，类型安全的 bean 映射
- **Hutool**: Java 工具集，提供丰富的工具方法
- **Jackson**: JSON 处理库，用于序列化和反序列化

### 测试框架

- **JUnit 5**: 单元测试框架
- **Mockito**: Mock 框架，用于模拟对象行为
- **Testcontainers**: 提供轻量级的测试环境，支持 Docker 容器

## 前端技术选型

### 核心框架

- **Vue 3.x**: 渐进式 JavaScript 框架，用于构建用户界面
- **Vite**: 新一代前端构建工具，提供快速的开发体验
- **TypeScript**: JavaScript 的超集，提供类型检查和更好的开发体验

### UI 组件库

- **Element Plus**: 基于 Vue 3 的桌面端组件库

### 状态管理

- **Pinia**: Vue 3 的轻量级状态管理库

### 路由管理

- **Vue Router 4**: Vue.js 官方路由管理器

### HTTP 客户端

- **Axios**: 基于 Promise 的 HTTP 客户端

### 构建工具

- **Webpack/Vite**: 模块打包工具
- **ESLint**: 代码规范检查工具
- **Prettier**: 代码格式化工具

## 为什么选择这些组件？

### 1. 成熟稳定

选择的都是业界广泛使用的成熟技术，拥有庞大的社区支持和丰富的文档资源。

### 2. 生态丰富

所选技术都有良好的生态系统，可以方便地集成其他组件和服务。

### 3. 学习成本低

大部分技术都是开发者熟悉的，降低了学习和使用成本。

### 4. 性能优秀

选择的技术在性能方面表现良好，能满足企业级应用的需求。

### 5. 可扩展性强

架构设计支持横向扩展，可以根据业务发展需要进行扩展。
