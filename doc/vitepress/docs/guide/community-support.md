## 社区渠道

### GitHub Issues

如果您发现了 bug 或者有任何建议，欢迎在我们的 [GitHub Issues](https://github.com/feihua666/particle/issues) 页面提出。在提交问题时，请尽量提供以下信息：

- 清晰的问题描述
- 复现步骤
- 相关代码片段或配置
- 环境信息（操作系统、Java 版本、Node.js 版本等）
- 错误日志或截图

### GitHub Discussions

对于一般性的问题、讨论和想法，可以使用 [GitHub Discussions](https://github.com/feihua666/particle/discussions)。在这里你可以：

- 提出使用问题
- 分享经验和技巧
- 讨论新功能建议
- 与其他开发者交流

## 贡献指南

我们欢迎任何形式的贡献，无论是代码贡献、文档改进还是问题反馈，无论你是新手还是资深开发者，都可以通过以下方式参与：

### 代码贡献

如果您想要贡献代码，请遵循以下步骤：

1. Fork 项目仓库
2. 创建功能分支 (`git checkout -b feature/AmazingFeature`)
3. 提交更改 (`git commit -m 'Add some AmazingFeature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 开启 Pull Request

### 文档贡献

文档是项目的重要组成部分，我们同样欢迎文档的改进：

1. 修复错别字和语法错误
2. 补充缺失的内容
3. 改进表达方式，使文档更易理解
4. 添加新的使用示例

### 测试和反馈

1. 测试新功能并提供反馈
2. 报告发现的 bug
3. 提出改进建议
4. 分享使用经验

### 代码规范

在提交代码时，请遵守以下规范：

1. **Java 代码规范**
   - 遵循阿里巴巴 Java 开发手册
   - 使用统一的代码格式化
   - 添加必要的注释和文档

2. **Vue 代码规范**
   - 遵循 Vue 官方风格指南
   - 使用 ESLint 和 Prettier 保持代码风格一致
   - 组件命名遵循 PascalCase

3. **Git 提交规范**
   - 使用有意义的提交信息
   - 遵循 conventional commits 规范
   - 每个提交应该只包含一个逻辑变更
