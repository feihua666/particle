# Axios 封装

对 Axios HTTP 客户端的封装，提供统一的请求拦截、响应处理和错误处理机制，属于与业务无关的技术组件。

## 功能特点

- 请求拦截器：统一添加认证token、设置请求头等
- 响应拦截器：统一处理响应数据格式、错误码等
- 错误处理：统一处理网络错误、超时等异常情况
- 请求取消：支持请求取消功能
- 请求重试：支持失败请求重试机制

## 设计理念

Axios 封装组件专注于提供统一的HTTP请求处理能力，不包含任何业务逻辑，可以在项目的任何需要发起HTTP请求的地方使用。

## 使用场景

- API 接口调用
- 文件上传下载
- 数据获取与提交
